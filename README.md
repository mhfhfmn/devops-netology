## Описание gitignore для Terraform

В каталог `terraform` был добавлен специализированный файл `.gitignore`, чтобы предотвратить случайное попадание служебных, временных и конфиденциальных файлов в публичный репозиторий. Благодаря этому файлу Git будет игнорировать:

1. **Локальную директорию `.terraform/`**
   Здесь хранятся скачанные бинарные файлы провайдеров (например, для AWS, Яндекса и др.) и внешние модули. Они занимают много места и автоматически скачиваются заново при выполнении команды `terraform init`, поэтому хранить их в Git нет смысла.

2. **Файлы состояний (`*.tfstate`, `*.tfstate.backup`)**
   Это важнейшие файлы, в которых Terraform записывает текущее состояние развернутой инфраструктуры. Их категорически нельзя пушить в репозиторий, так как в них часто хранятся секретные данные, пароли и приватные ключи в абсолютно открытом (незашифрованном) виде.

3. **Файлы с переменными и секретами (`*.tfvars`, `*.tfvars.json`)**
   Обычно в таких файлах разработчики передают учетные данные, токены и специфичные настройки окружения, которые не должны стать достоянием общественности.

4. **Логи падений и временные файлы блокировок**
   Файлы вроде `crash.log` или `.terraform.tfstate.lock.info` нужны только локально в момент работы утилиты для диагностики ошибок или предотвращения одновременного изменения состояния разными пользователями.
